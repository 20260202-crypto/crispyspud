Design Choices

Layout changes from the first plan

  • The logo, search box and Orders button share one top row, and the navigation is a single pill bar.
  • Category blocks include a short label, and the products are stacked rows (picture, name, price, button) instead of side-by-side cards.
  • Sections were renamed: Food is now Fries, Items is now Merch, and Cart is now Orders. Checkout stays the same.
